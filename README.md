# Zhentao Liang - Personal Website

A lightweight academic website built with Quarto.

## Local preview

```bash
quarto preview
```

## Render

```bash
quarto render
```

## Routine updates

- Publications: edit `publications.yml`.
- Projects: edit `projects.yml`.
- Biography and homepage: edit `index.qmd`.
- Web CV: edit `cv/index.qmd`.
- PDF CV: replace `assets/pdf/cv.pdf` while keeping the same filename.

Pushing to `main` or `master` triggers the GitHub Pages workflow.
